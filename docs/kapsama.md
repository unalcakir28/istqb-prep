# Kapsama Raporu

> ⚠️ Bu dosya `npm run stats` tarafından **otomatik üretilir** (F0-13). Elle düzenleme.

**Son güncelleme:** henüz üretilmedi — script yazılmadı.

## Özet (hedef)

| Metrik | Şu an | M1 hedefi | M3 hedefi |
|---|---|---|---|
| Yayınlanmış soru | 1 | 120 | 300 |
| Kapsanan LO (≥1 soru) | 1 / 64 | 64 / 64 | 64 / 64 |
| Kapsanan LO (≥3 soru) | 0 / 64 | — | 64 / 64 |
| Çeldirici gerekçesi doluluğu | %100 | %100 | %100 |

## Rapor ne gösterecek

- LO başına yayınlanmış soru sayısı (en az sorusu olandan başlayarak sıralı)
- Bölüm başına soru sayısı ve hedef dağılımdan sapma
- K-seviyesi başına soru sayısı
- Her blueprint LO grubu için havuz yeterli mi? (grup başına düşen sorunun **≥3 katı** olmalı)
- `status` dağılımı: draft / review / published / retired
- `meta.reviewedBy` boş olan yayınlanmış sorular (olmamalı)
