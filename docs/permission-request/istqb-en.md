# Permission request to ISTQB (English)

**To:** https://istqb.org/contact/ (or the Exam Working Group, which the notice names as the
document owner)
**Subject:** Written approval requested — CTFL v4.0.1 sample exams in a free, non-commercial
preparation platform

---

Dear ISTQB Exam Working Group,

My name is Ünal Çakır. I maintain **ISTQB-PREP**, a free and open-source exam preparation platform
for ISTQB certifications, built and run by one person at no charge to anyone. It works in Turkish
and English and currently targets CTFL v4.0.1.

**My request:** written approval to reproduce the questions and answer keys of CTFL v4.0.1 Sample
Exams A, B, C and D verbatim inside this platform.

I am asking because the copyright notice on page 2 of each sample exam states:

> Any other use of this sample exam is prohibited without first obtaining the approval in writing of
> the ISTQB®.

## Where the project stands today

The platform contains **no official questions**. Every question in its pool is original, written
from scratch against the syllabus learning objectives — a rule the project has documented and
enforced since before its first release. The official sample exams appear only as links to the
publisher's own pages.

This request is therefore for an addition that would be made if approval is granted, not a request
to excuse an existing use.

## What I commit to

If approval is granted:

- **No commercial use of any kind.** No advertising, no subscription, no fee, no donations.
- **Attribution on every question:** the authors and the ISTQB® named as source and copyright
  owners on the question's own screen, with the set name and document version visible.
- **The full copyright notice** reproduced unaltered on the platform's sources page.
- **No modification.** Question text, options and answer keys stay exactly as published, with the
  syllabus version shown as a badge on each question.
- **Official and original questions labelled separately**, with the candidate choosing which set to
  work with. A question's provenance is never ambiguous on any screen.
- **Immediate removal on request**, without asking for a reason.
- No suggestion anywhere that the platform is affiliated with or endorsed by ISTQB or any member
  board. A statement of independence is already published.
